## 1. 品牌

## 2. 侧栏 v3：任务导向（对标 Nektony App Cleaner & Uninstaller）

Nektony 的铁律：**侧栏每一项 = 用户的一个问题**（要卸载什么/残留在哪/哪些自启动），不是数据分类。来源不是导航轴，是行内元数据 + 工具栏过滤器。

新侧栏结构：

```
┌──────────────┐
│ 状态卡: 0 项待更新 │
│ [立即扫描]      │
├──────────────┤
│ 任务            │
│  ⟳ 待更新    7 │  ← "有什么要更新？"
│  ▤ 全部软件 135 │  ← "装了什么？"
│  ○ 手动安装  25 │  ← "哪些不受管？"
│  ⊘ 已忽略      │  ← "我跳过了哪些？"
├──────────────┤
│ 来源(过滤)       │  ← 从导航降级为快捷过滤（点击=内容区按源过滤）
│  ● Homebrew 34 │
│  ● npm      13 │
│  …             │
└──────────────┘
```

- 「来源」从主导航降级：保留为侧栏下方的快捷过滤区 + 内容工具栏过滤 chips，行内来源徽章保留（价值=告诉你这软件**归谁管、怎么更新、怎么卸**）
- 计数徽章随扫描实时刷新

## 3. 详情浮窗
