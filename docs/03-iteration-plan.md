## 迭代 3 · 核心承诺补全 + 规范化整风（1-1.5 周）🚧 进行中

**目标**：补上"普通应用更新检测"这个最大缺口；全局检索打通；UI 规范落地。

1. **Sparkle 应用更新扫描**（引擎新增"应用"源）：扫 `/Applications` + `~/Applications` + **自动发现 `/Volumes/*/Applications`（外置盘，含用户 Xcode 实测场景）**；读 Info.plist（CFBundleShortVersionString/CFBundleIdentifier/SUFeedURL）；`_MASReceipt` 存在 → 归 App Store 渠道跳过 Sparkle 检测；有 SUFeedURL → 拉 appcast XML（5s 超时）解析最新版本；`SUStandardVersionComparator` 语义复刻为全项目唯一版本比较入口（完整单测）
2. **更新动作**：应用项"更新"= 唤起应用自更新（NSWorkspace.open）+ 引导提示；cask 受管的仍走 brew 代更
3. **全局检索打通**：清单扫描目录扩到外置盘卷；扫描页搜索覆盖"应用"源；工具栏搜索提供"在全部软件中查找 N 项"跨页跳转
4. **设计规范 v1 落地**（docs/08）：新建 DesignSystem.swift 唯一 token 出口；按 §7 问题台账全量清零文案/命名/称呼
5. 新增维护者通道：`--scan` 报告含"应用"源计数

**验收**：build 零警告；全部测试绿（版本比较器 ≥8 用例、appcast 解析 fixture ≥4 用例）；`--scan` 的"应用"源计数与手工 grep SUFeedURL 基准一致；外置盘 Xcode 出现在全部软件；docs/08 §7 台账逐条清零（截图验收）。
