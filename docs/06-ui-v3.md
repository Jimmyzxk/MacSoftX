# 06 · UI v3：Mac 原生结构重构 + 全部软件清单（迭代 2）

> 背景：迭代 1.5 用户复核判定「有进步但仍丑、像 5 年前；整体动线像新手作品」。
> 对标结论（成熟 Mac 软件=Version Tracker/MacUpdater/CleanMyMac/Raycast + Apple Liquid Glass 指南）：
> 1. **侧栏导航 + 图标列表**是这类软件的标准结构（MacUpdater/Version Tracker 均如此）
> 2. Liquid Glass 的正确用法：**玻璃给侧栏/工具栏/浮动件，内容区实底克制**（Apple 官方 adopting-liquid-glass 指南）
> 3. CleanMyMac：把繁琐维护变成"任务感"+有信息量的动画；Raycast：密度+键盘优先
> 4. 真实应用图标是信任感的最大来源——图标砖/色块是糊弄

## 0. 上版「新手感」病灶清单（本版全部根除）

| 病灶 | 根除方式 |
|------|----------|
| 单列卡片页=网页思维 | NavigationSplitView 三区结构：侧栏+内容+底部状态栏 |
| 巨环居中占 1/3 屏像加载动画 | 环缩为侧栏头部紧凑摘要（≤48pt），内容区还给数据 |
| 图标砖冒充应用图标 | cask/mas 用 NSWorkspace 真图标（/Applications 匹配），formulae 用 brew 风格 monogram |
| 文案啰嗦（"共扫描到…其中…"） | 文案减半，多数据少解释 |
| 无工具栏/快捷键/右键菜单/状态栏 | 全补齐（见 §2） |
| 一屏 3 张卡密度过低 | 行式列表，一屏 8-12 行，密度向 MacUpdater 看齐 |
| 琥珀环+蓝按钮+彩 chips 色彩打架 | 全局只有一个强调色（系统蓝），生态色只做 4-6pt 小标记点 |

## 1. 信息架构（三区）

```
┌─────────┬──────────────────────────────┐
│ 侧栏     │ 工具栏：搜索 · 分段过滤 · 排序      │
│ (玻璃)   ├──────────────────────────────┤
│ ◎ 扫描 7 │ 内容区（实底，行式列表，一屏 8-12 行）│
│ ▤ 全部软件│ …                             │
│ ⊘ 已忽略 │ …                             │
│         ├──────────────────────────────┤
│ 新鲜度摘要│ 状态栏：上次扫描 17:33 · 2 源 · 7 项 │
└─────────┴──────────────────────────────┘
```

- 侧栏：`扫描`（默认）/`全部软件`/`已忽略`（占位灰显）/(历史、设置预留)；头部新鲜度摘要=紧凑数字行（如 `7 待更新 · 覆盖 2 源`），不是大环
- 工具栏（SwiftUI Toolbar，玻璃）：搜索框、分段过滤（全部/应用/命令行）、排序菜单（名称/来源/大小）、`⌘R` 重新扫描按钮
- 快捷键：⌘F 搜索、⌘R 扫描、⌘1/⌘2 切换侧栏页
- 右键菜单（更新列表行）：复制升级命令 / 忽略此项 / 在 Finder 中显示（cask 应用）/ 重新扫描
- 底部状态栏：上次扫描时间 · 启用源数 · 总项数

## 2. 扫描页（原更新列表 v3）

- 行式列表（非卡片）：**40px 真实应用图标**（cask/mas 从 /Applications 匹配 NSWorkspace.icon；formula/cli 用 brew 琥珀 monogram 圆角小砖）+ 名称 + 类型小标 + 版本胶囊（旧灰新亮）+ 状态徽章 + 行尾「更新」钮
- 排序默认：按源分组、组内按名；过滤 chips 收进工具栏分段控件（全部/应用/命令行）
- 空态/错误横幅保留（错误横幅移到内容区顶部通栏，细带样式）

## 3. 全部软件页（新增，用户需求）

**目标：一台电脑装了什么，一页看全，好规整。**

- 数据源（引擎新增只读 `inventory` 能力，全部走 ShellRunner）：
  - `/Applications` + `~/Applications` 扫描：名称、CFBundleShortVersionString、真图标、路径；交叉标记「由 brew cask 管理」「App Store（mas 已知 id）」
  - `brew list --json=v2`（formulae+casks 已装版本）
  - `mas list`、`npm ls -g --json`、`pipx list --json`、`uv tool list`、`gem list --local`、`cargo install-update -l`（有则列，缺源自动隐藏）
- 列：图标（真实优先）/ 名称 / 版本 / 来源徽章（Homebrew·cask·npm·App Store·独立下载…）/ 管理状态（受管/游离）
- 交互：搜索、按来源过滤、排序（名称/版本/来源）；行右键：在 Finder 中显示 / 复制名称 / 复制路径
- 顶部统计条：`X 应用 · Y CLI · 覆盖 N 源 · M 游离项`（游离=独立下载未受任何包管理器管辖，是"规整"的核心线索）
- **性能红线**：应用扫描异步不阻塞 UI；列表懒加载；结果缓存，二次打开秒开
- **只读 MVP**：卸载/清理是破坏性操作，列为迭代 3+ 候选，本版不做

## 4. 菜单栏气泡

保留 .window 玻璃气泡，视觉对齐 v3：迷你摘要行（数字+源点）+ 最近 5 条行式项 + 底部按钮排；去掉大环。

## 5. 工程约束

- 引擎只新增 inventory 只读命令（全走 ShellRunner）；fetchOutdated/update/ScanMode 契约零改动；`--scan` 不变，新增 `--inventory` 验收通道（输出清单 JSON）
- 既有 22 测试全绿；inventory 解析用 fixture 单测（brew list json / npm ls json / mas list 文本）
- 主线程规约注释保留；GlassEffect 只用于侧栏/工具栏/气泡/浮动件，内容区实底
- 全部中文文案；深浅色自适应；reduceMotion 降级

## 6. 验收标准（维护者）

1. build 零警告；测试全绿（含新 fixture）；--scan 与 --inventory 双通道真机对账
2. 视觉截图对照：侧栏+更新页（浅/深）、全部软件页、气泡；结构必须与 MacUpdater 同级（侧栏+真图标+行列表+工具栏+状态栏五件套齐全）
3. 密度：1440pt 高度下一屏 ≥8 行内容
4. 真图标：cask 应用行显示真实 app 图标
5. 用户视觉复核通过才算收口

## 7. 本版不做

卸载/清理（破坏性，迭代 3+ 需双确认流程）、历史页、设置页完整版、AI 风险徽章、多语言、真实大小统计（列了性能成本高，先不做）。
