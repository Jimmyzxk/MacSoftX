# 09 · 美术指引（视觉打磨专项，迭代 2.5）

> 性质：纯视觉迭代，零功能新增。对标气质：CleanMyMac X 的任务感 × Raycast 的密度纪律 × 系统原生材质。
> 验收：气泡可机器截图对比；主窗由用户终审。

## 1. 诊断（当前 vs 设计感标准）

| 部位 | 现状 | 病因 |
|------|------|------|
| 侧栏 | 默认 List 裸奔：纯文字行、无图标、无计数、无分组头 | "没设计的侧栏"是简陋感第一来源 |
| 内容区行 | 单行单层信息、尾缀按钮常驻 | 无层级、无呼吸、按钮噪音大 |
| 气泡按钮排 | 系统灰色凸起按钮 | 2015 系统设置面板感 |
| 全局 | 字号层级拉不开、无 hover 态、分割线到处都是 | 平面无节奏 |

## 2. 类型标尺（全 app 只许这六档）

| 层级 | 规格 | 用途 |
|------|------|------|
| 大数字 | 34pt rounded bold | 侧栏头部剩余数 |
| 页面标题 | 22pt bold | （主窗标题栏已系统化，内容区少用） |
| 区块头 | 13pt semibold secondary | 分组标题 |
| 正文 | 13pt regular（名称行 13pt medium） | 行主文本 |
| 元信息 | 11pt regular secondary | 副标题/路径/时间 |
| 徽章 | 11pt rounded medium | 计数/版本胶囊 |

## 3. 侧栏规范（重做）

- 宽度 200pt；系统侧栏材质（不要自绘背景）
- **分组**：`更新`（扫描）/ `资料库`（全部软件、已忽略）——Section 头 11pt 大写 secondary
- 行结构：SF Symbol 图标 15pt secondary + 标签 13pt + 右对齐计数徽章（11pt rounded，≥20pt 宽胶囊，有数字才显示）
- 选中态：8pt 圆角实底（quaternary fill）；hover：同形 50% 透明度
- 头部摘要：保留但重设计——大数字 + `项待更新` 11pt + 覆盖源点（≤6pt 色点），无背景卡片

## 4. 内容区行规范（重做）

- 行高 52pt；左 36pt 图标；**两行结构**：行 1=名称 13pt medium，行 2=元信息 11pt secondary（`来源 · 当前版本 → 新版本`）
- 尾缀操作钮**默认隐藏，行 hover 时显现**（永远可见的按钮列 = 噪音源）
- 行 hover 背景：primary 4%、8pt 圆角；**行间不用分割线**，用 2pt 间距；分组间 16pt + 8% 透明 hairline
- 版本胶囊与徽章沿用 docs/08 token；每屏 ≥8 行

## 5. 气泡（微调）

- 底部按钮排：`全部更新` 用 `.glassProminent`，其余 `.borderless` 文字钮（去灰底凸起）
- 删除与绿勾重复的状态文字行（勾已表达"系统最新"）；留 `上次扫描 时间` 一行 11pt secondary

## 6. 全局纪律

- 内容区背景=系统背景色；除生态源点与图标砖底外**无彩色**；hover/选中只用 primary 透明度阶
- 阴影只给浮动件（气泡/弹窗），行与卡片无阴影
- reduceMotion 降级不变；docs/08 全规范继续生效

## 7. 明确不做

新功能、新页面、引擎改动、网格视图（v3.5 再说）、动效加强（先做减法）。
