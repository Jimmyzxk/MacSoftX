# 05 · UI 视觉重构规范（迭代 1.5）

> 背景：迭代 1 功能验收通过后，用户判定现有 UI「十几年前的产物」。产品拍板：借 macOS 26/27 的 **Liquid Glass** 设计语言做整体视觉重构。
> 本迭代 = 纯表现层 + 轻量信息架构升级，**引擎层一行不动**。

## 0. 基线调整（随本迭代生效）

- **最低系统 macOS 14 → 26**：解锁 glassEffect 等全套 Liquid Glass API，摆脱旧系统包袱（用户机器为 27，用户明确拍板甩包袱）。
- 若个别 API 名与 SDK 实际签名有出入：用最接近的系统原生等价物实现，并在汇报中标注。

## 1. 设计概念：「新鲜度驾驶舱」

一句话：把"更新列表"升级为"系统新鲜度仪表盘"——用户打开的不是待办清单，而是一块玻璃质感的状态驾驶舱。三个记忆点：**一颗环、一套生态色、一排会呼吸的卡片**。

## 2. 菜单栏气泡（MenuBarExtra 改 .window 样式）

从纯文字下拉升级为玻璃气泡迷你面板（`.menuBarExtraStyle(.window)`）：

```
┌──────────────────────────┐
│  ◔ 7        环形仪表：剩余更新数居中   │
│  系统基本新鲜（状态文案）              │
├──────────────────────────┤
│ ● git      2.43 → 2.44  [更新] │  ← 最近 5 条迷你卡片
│ ● node     20.11 → 21.6 [更新] │     生态色点 + 名字 + 版本胶囊
│  …                            │
├──────────────────────────┤
│ [全部更新]  [打开驾驶舱]  [设置]     │  ← 玻璃按钮排
└──────────────────────────┘
```

## 3. 主窗「驾驶舱」

单卡片玻璃结构（无传统三区侧栏），从上到下：

1. **Hero 区**：大号渐变圆环仪表（按生态色分段着色，环心大数字=剩余更新数 + 「项待更新」）＋右侧「全部更新」主按钮（.glass 主按钮，更新中变进度态）
2. **过滤条**：搜索框（圆角玻璃）＋ 生态过滤 chips（全部/Homebrew/App Store/npm/…，选中态实色、未选中玻璃胶囊）
3. **更新卡片区**：每行一张圆角玻璃卡：
   - 左：生态图标砖（圆角渐变底 + SF Symbol；formula=terminal 图形、cask=app 图形、mas=App Store 图形；真实 app 图标读取列为迭代 4 增强，本迭代不做）
   - 中：名称（主字重）＋ 版本变迁胶囊「2.43.0 → 2.44.0」（旧值灰、新值亮、箭头小）＋「需管理员」「需登录」状态徽章
   - 右：「更新」玻璃小按钮；状态流转＝更新中（旋转 symbol + shimmer 微光）→ 成功（绿勾 bounce 动画 + 新版本号）→ 失败（红色错误摘要，最多两行）
4. **空状态**：大号渐变 ✓ 环 +「一切都新鲜」+ 上次扫描时间（这是庆祝时刻，不是空白页）
5. **错误横幅**：lastErrors 必须可见（玻璃警告条，含源名与原因摘要）——迭代 1 的教训：错误不许再被吞

## 4. 视觉语言 tokens

- **材质**：Liquid Glass 优先（.glassEffect / GlassEffectContainer / .buttonStyle(.glass) 系），卡片圆角 20-28pt，留白慷慨，层级靠材质深浅不靠分割线
- **生态色板**（点、环分段、图标砖共用）：Homebrew 琥珀、App Store 蓝、npm 红、pip/uv 黄、Cargo 橙棕、Gemston(e) 宝石红——每源一色，全 app 一致
- **字体**：数字用 rounded 设计（版本号、环心大数）；正文默认
- **深浅色**：全自适应，玻璃材质自动透壁色；不写死背景色

## 5. 动效

- SF Symbols 原生动画：扫描时 icon pulse/rotate，成功勾 .bounce，更新中转圈
- 卡片状态切换 spring 过渡；列表增删带 move/opacity
- 尊重系统「减弱动态效果」（@Environment(\.accessibilityReduceMotion) 降级为直切）

## 6. 工程约束

- **只动表现层与 AppState 对外接口**：Provider/ShellRunner/ScanMode/解析器一行不改；--scan 输出契约不变
- 主线程规约延续：App.main 以 assumeIsolated 普通代码启动（upmacApp.swift 顶部规约注释保留）
- 新增交互：搜索过滤（本地内存过滤即可）、全部更新（串行逐项执行复用现有 provider.update，逐项状态流转；正式批量队列仍是迭代 4 范畴）
- 「需管理员」行按钮禁用、「需登录」行禁用+提示——红线不动
- 全部文案中文；测试保持全绿（解析器/ShellRunner 不受影响，UI 逻辑能测则测）

## 7. 验收标准（维护者侧）

1. build 零警告；swift test 全绿；--scan 对账数量不变
2. 菜单栏气泡：玻璃质感迷你面板可见，环形仪表数字=真实剩余数
3. 主窗：驾驶舱结构完整（环/过滤条/卡片/空态/错误横幅），深浅色各截一张
4. 点单项「更新」真实升级仍成功（用户侧复验）
5. 维护者视觉验收：截图逐项对照本规范，视觉不达标打回重做

## 8. 明确不做（本迭代）

真实 app 图标读取、批量勾选队列、设置页改版、AI 风险徽章（占位概念留待后续迭代）、多语言。
