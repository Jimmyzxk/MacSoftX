# MSI App Icon 设计方案与规范

> 产品定位：最好用的 Mac 软件管理工具（聚合更新检测 + 软件清单 + 清理）  
> 品牌气质：现代、玻璃质感、可信赖的效率工具  
> 画布规范：1024 × 1024 标准画布，严格遵循 macOS Big Sur / Sonoma / Sequoia 连续曲率圆角矩形（Squircle）与多层物理光学质感。

---

## 一、方案全景与精修演化

用户已选定**方案 C「软件魔方」**作为正式演进方向。现保留原概念设计，并基于方案 C 输出精修版（C1）、演化版（C2）以及配套的菜单栏模板变体。

| 方案 | 核心符号 | 色彩意象 | 设计说明 |
| :--- | :--- | :--- | :--- |
| **方案 C<br>「原版魔方」**<br>*(基准归档)* | **三颗圆角方块 + 负空间 M** | 蓝 / 薄荷绿 / 冰透白 | 三枚圆角应用方块悬浮交叠，克制调和蓝、青绿与冰透白，以负空间自然勾勒 M 字母。 |
| **方案 C1<br>「精修版」**<br>*(几何极简)* | **锐化两翼 + 紧凑菱形 + 强对比 M** | 系统蓝 → 高亮青渐变收敛 | 方块轮廓收至 rx=32 更具工程精密度，间隙扩大 8.3% 并强化 M 负空间光感，顶部菱形收紧微透，色彩收敛至蓝青族。 |
| **方案 C2<br>「演化版」**<br>*(🔥 App Icon 推荐)* | **魔方基座 + 青色循环箭头小徽记** | 系统蓝 → 高亮青渐变统一 | 继承 C1 锐化规格与大间隙负空间，中央顶部演化为透光青色循环双箭头微透镜徽记，强力呼应「更新检测与软件管理」第一心智。 |
| **menuicon-macsoftx<br>「菜单栏同构版」**<br>*(🔥 菜单栏首推)* | **双圆角竖片 + 循环更新双箭头** | 纯黑剪影、透明底 (Template) | 专为 16px 菜单栏状态栏优化，完整继承 C2 骨架与更新语义，彻底告别通用箭头平庸感。 |
| **menuicon-m<br>「菜单栏 M 字标」**<br>*(菜单栏备选)* | **双圆角竖片 + 顶部中心菱形** | 纯黑剪影、透明底 (Template) | 极简主义负空间字母标，由几何实体剪影留白自然勾勒粗体 M 字形。 |

## 二、方案 C 演进推荐与深度理由

### 🏆 最终选定推荐：首选方案 C2「演化版（循环箭头徽记）」

#### 1. 业务功能语义彻底闭环（兼得魔方美感与更新直觉）
- 原版 C 最具设计感与现代感，但唯一的潜在考量是缺少对「聚合更新」这一第一核心行为的直观指示。
- **方案 C2** 在保留方案 C 模块化软件魔方（代表 GUI 应用、CLI 包管理与清单清理）这一惊艳底座的同时，将中央核心雕琢为一枚**「青色循环更新双箭头微透镜小徽记」**。
- 视觉语义形成完美自洽：**“模块化软件清单（两翼魔方）围绕更新引擎（中央循环徽记）协同流转，整体在负空间凝聚为品牌 M 字母”**。

#### 2. M 负空间对比度大幅强化，小尺寸辨识无忧
- 间距从原版的 192px 扩大至 208px（增加 8.3%），两翼方块圆角从 rx=42 收紧至 rx=32，整体造型硬朗利落；
- 负空间底部注入双层高斯弥散漫反射蓝光（`#00e5ff`），并在切线处增设 8px 纯白高光线，在 32px 甚至 16px 菜单栏极小尺寸下，M 字母轮廓依然清晰锐利。

#### 3. 品牌色收敛统一，现代科技质感跃升
- 抛弃了原版 C 中略显分散的薄荷绿色块，将色彩全面收敛至与方案 A 同族的**「系统蓝（`#0055FF` ~ `#0A84FF`）→ 高亮青（`#00C7BE` ~ `#00F5D4`）」**；
- 左右两块形成跨越负空间的统一渐变冷光流动，视觉重心更聚焦、更具 macOS 14+ Sonoma / Sequoia 原生效率工具的清透品质。

## 四、macOS 菜单栏状态栏模板图标规范与设计意图

由于 MSI 为常驻菜单栏工具，菜单栏角标是用户接触最频繁的品牌触点。此前使用的通用系统循环箭头缺乏品牌归属性与辨识度。为此专门打造两套 32×32 纯黑单色剪影模板图标（Template Icon）：

### 1. 变体一：`menuicon-macsoftx.svg`（🔥 推荐首选 · C2 专属同构）
- **设计意图**：
  - **1:1 映射 App 主图标（C2）**：提取 C2 最具代表性的核心几何形态——左右双圆角竖片（代表应用清单与包管理）+ 中央双向回环更新箭头（代表聚合检测与更新流转）。
  - **16px 极限物理尺寸可读性**：为避免在 16px/18px 下粘连，舍弃了次要的倒角与透镜边线；将中心通道扩大至 14px，箭身加粗至 1.8px，双箭头强化为锐角三角实体，并在双竖片之间保持至少 3px 安全间隙，即便在非 Retina 或紧凑状态栏中依然能清晰分辨“双片夹着更新双箭头”的独有构造。
  - **负空间呼应**：双竖片与箭头的整体组合在视觉潜意识中依然保留了 M 字形的起伏轮廓。

### 2. 变体二：`menuicon-m.svg`（纯几何备选 · M 字标）
- **设计意图**：
  - **极致凝练的品牌字标**：由左右两片实心圆角竖柱与上方一颗 45° 旋转的实心菱形构成。
  - **负空间自然成字**：三块黑色几何形体相互留白，以 45° 斜角自然刻画出一条锐利的「M」字通道。
  - 适合极致推崇纯几何、不希望菜单栏出现箭头符号的设计偏好。

### 3. 系统集成规范
两款 SVG 均为 32×32 viewBox、纯黑 `#000000` 填充、透明背景。在 macOS 中设置 `image.isTemplate = true` 后，系统会自动根据菜单栏状态（浅色壁纸下为深炭灰、深色壁纸下为纯白、点击高亮时为纯白）完成像素级反色渲染。

## 五、后续转 `.icns` 的建议与规范

macOS 要求 App 图标必须为包含多分辨率位图的 `.icns` 打包文件，或者由 Xcode Asset Catalog (`AppIcon.appiconset`) 统一编译。

```bash
# 1. 创建临时图标集目录
mkdir -p AppIcon.iconset

# 2. 从推荐的 concept-c2.svg 生成 10 档高清分辨率位图
rsvg-convert -w 16 -h 16 concepts/concept-c2.svg -o AppIcon.iconset/icon_16x16.png
rsvg-convert -w 32 -h 32 concepts/concept-c2.svg -o AppIcon.iconset/icon_16x16@2x.png
rsvg-convert -w 32 -h 32 concepts/concept-c2.svg -o AppIcon.iconset/icon_32x32.png
rsvg-convert -w 64 -h 64 concepts/concept-c2.svg -o AppIcon.iconset/icon_32x32@2x.png
rsvg-convert -w 128 -h 128 concepts/concept-c2.svg -o AppIcon.iconset/icon_128x128.png
rsvg-convert -w 256 -h 256 concepts/concept-c2.svg -o AppIcon.iconset/icon_128x128@2x.png
rsvg-convert -w 256 -h 256 concepts/concept-c2.svg -o AppIcon.iconset/icon_256x256.png
rsvg-convert -w 512 -h 512 concepts/concept-c2.svg -o AppIcon.iconset/icon_256x256@2x.png
rsvg-convert -w 512 -h 512 concepts/concept-c2.svg -o AppIcon.iconset/icon_512x512.png
rsvg-convert -w 1024 -h 1024 concepts/concept-c2.svg -o AppIcon.iconset/icon_512x512@2x.png

# 3. 使用 macOS 系统自带工具压制成 icns
iconutil -c icns AppIcon.iconset -o AppIcon.icns

# 4. 清理临时切图目录
rm -rf AppIcon.iconset
```
